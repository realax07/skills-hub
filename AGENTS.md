# Инструкция для код-агентов

Этот репозиторий — хаб скиллов по темам. Карта и описание — в [README.md](README.md).

## Если тебя попросили установить скиллы

1. Определи, какой ты агент, и найди свой `id` в [agents.conf](agents.conf)
   (`claude`, `codex`, `opencode`, `qwen`, `hermes`, `zcode`, `agents`).
2. Посмотри, что есть: `./install.sh list`
3. Установи (на Windows — `.\install.ps1` с теми же командами):
   - глобально для себя: `./install.sh install -a <id>`
   - только тему/скилл: добавь `-t <тема>` или `-s <скилл>`
   - в текущий проект: `./install.sh install -a <id> -p .`
4. Проверь: `./install.sh status -a <id>` и сообщи пользователю, что скиллы подхватятся после перезапуска агента.

Если репо не склонирован: `curl -fsSL https://raw.githubusercontent.com/realax07/skills-hub/main/install.sh | bash -s -- install -a <id>`.

Если твоего агента нет в `agents.conf` — не угадывай молча: найди в его документации папку для `SKILL.md`,
добавь строку в `agents.conf` (или `agents.local.conf` для локальной правки) и скажи пользователю, что добавил.

## Если тебя попросили создать скилл

- Место: `<тема>/skills/<имя>/SKILL.md`, начинай с копии `_template/skill/`.
- `name` во frontmatter = имя папки (kebab-case), уникально во всём репо.
- `description` — одна строка до 1024 символов: что делает и когда применять.
- `SKILL.md` короткий; подробности — в `references/`, скрипты — в `scripts/`.
- Пиши скилл агент-нейтрально: без инструментов и путей, специфичных для одного агента.
- Обнови таблицу скиллов в `README.md` темы; для новой темы — таблицу тем в корневом README.

## Правила репо

- Инсталляторы не трогают папки, которые ставил не хаб (без `--force`).
- `install.sh` должен работать в bash 3.2 (macOS): без ассоциативных массивов и `mapfile`.
- Логика `install.sh` и `install.ps1` должна совпадать — правишь один, правь и второй.

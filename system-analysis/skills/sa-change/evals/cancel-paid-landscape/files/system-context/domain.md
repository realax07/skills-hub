# Предметная область

## Сущности

### Заказ (Order)
Что покупатель купил и на какую сумму. Поля: покупатель, статус, сумма в копейках, платёж Stripe, время создания. Создаёт покупатель (order-checkout), меняют вебхук оплаты, менеджер, автоотмена, очередь отгрузки.

### Позиция (OrderItem)
Артикул, количество и цена на момент оформления. Создаются вместе с заказом и не меняются.

### Пользователь (User)
Почта и роль. Создание пользователей — вне сервиса (токен выдаёт внешний сервис входа; см. Q-008).

## Состояния и переходы

### Заказ (Order.status)
- NEW → PAID: вебхук успешной оплаты; шлётся чек (order-payment)
- NEW → CANCELLED: отмена покупателем, менеджером или автоотменой через 30 мин (order-cancellation)
- PAID → REFUNDED: отмена менеджером или администратором с полным возвратом (order-cancellation)
- PAID → SHIPPED: склад принял отгрузку (order-shipping)
- SHIPPED, CANCELLED, REFUNDED — конечные: отмена и отгрузка из них дают 409

## Роли и права

| Действие | Покупатель | Менеджер | Администратор |
|---|---|---|---|
| Оформить заказ | ✓ | ✓ | ✓ |
| Список заказов | свои | все | все |
| Карточка заказа | своя | любая | любая |
| Отменить NEW | свой | ✓ | ✓ |
| Отменить PAID с возвратом | ✗ (Q-004) | ✓ | ✓ |
| Запустить отгрузку | ✗ | ✓ | ✓ |

## Бизнес-правила и константы

- В заказе 1–50 позиций (order-checkout; по PRD 30 — Q-001).
- Автоотмена: NEW старше 30 минут, проверка раз в 15 минут (order-cancellation; по PRD 1 час — Q-003).
- Список заказов — не больше 100 (order-viewing).
- Передача на склад — до 5 попыток (order-shipping).
- Суммы — в копейках, валюта платежа — рубли.

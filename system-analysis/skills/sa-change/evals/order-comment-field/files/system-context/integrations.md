# Внешние системы

Всё, с чем сервис обменивается данными за пределами своего кода и своей БД: кого вызывает он и кто вызывает его.
Уровень — поведение и договорённости; протоколы, клиенты и развёртывание — дело архитектурного описания.

## Stripe — приём оплаты и возвраты
- **Направление:** обе стороны: мы создаём платёж и возврат; Stripe присылает вебхук об оплате
- **Когда:** создание заказа (order-checkout), подтверждение оплаты (order-payment), отмена оплаченного (order-cancellation)
- **Что передаём / получаем:** сумма, валюта RUB, id заказа в метаданных; получаем id и секрет платежа, события оплаты
- **При отказе:** ошибка Stripe при создании заказа — запрос падает с 500, заказ остаётся NEW без платежа; ретраев нет
- **Настройки:** STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET
- **В коде:** src/integrations/stripe.ts:3, src/routes/webhooks.ts:8
- **Вопросы:** Q-006, Q-007

## Склад-партнёр (api.warehouse-partner.ru) — отгрузка
- **Направление:** мы → они
- **Когда:** очередь отгрузки после запуска менеджером (order-shipping)
- **Что передаём / получаем:** id заказа как внешний номер, артикулы и количество; персональных данных нет
- **При отказе:** не-2xx — исключение, очередь повторяет до 5 раз; после — заказ остаётся PAID без сигнала
- **Настройки:** WAREHOUSE_API_URL, WAREHOUSE_TOKEN
- **В коде:** src/integrations/warehouse.ts:3
- **Вопросы:** Q-005

## Почта (SMTP через nodemailer) — чеки
- **Направление:** мы → они
- **Когда:** после оплаты (order-payment)
- **Что передаём / получаем:** почта покупателя (персональные данные), номер и сумма заказа
- **При отказе:** ошибка не перехватывается: вебхук падает с 500, Stripe повторит уведомление, но заказ уже PAID — чек не уйдёт
- **Настройки:** SMTP_HOST
- **В коде:** src/integrations/mailer.ts:4

## Сервис входа — выдаёт токены
- **Направление:** они → мы (токен в заголовке)
- **Когда:** каждый запрос к API заказов
- **Что передаём / получаем:** id и роль пользователя из подписанного токена
- **Настройки:** JWT_SECRET
- **В коде:** src/auth.ts:4
- **Вопросы:** Q-008

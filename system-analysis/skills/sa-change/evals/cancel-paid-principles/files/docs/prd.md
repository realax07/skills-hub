# PRD: Сервис заказов (v1)

## Цель
Покупатель оформляет заказ и оплачивает его картой. Менеджер отгружает оплаченные заказы через склад-партнёр.

## Требования
1. Заказ содержит от 1 до 30 позиций.
2. Цена позиции берётся из каталога на момент оформления.
3. Неоплаченный заказ отменяется автоматически через 1 час.
4. Покупатель может отменить заказ до отгрузки; оплаченный — с полным возвратом денег.
5. После оплаты покупатель получает чек на почту.
6. Отгрузку делает менеджер; заказ передаётся на склад.
7. Администратор видит все заказы.

## Вне рамок v1
Частичные возвраты, промокоды.

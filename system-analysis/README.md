# system-analysis

Набор скиллов **sa-*** для системного анализа при переводе проекта на агентную разработку по SDD:
снять с кода, как система работает сейчас, в формате [OpenSpec](https://github.com/Fission-AI/OpenSpec)
и собрать рядом карту системы и открытые вопросы о внешнем мире. Скиллы говорят на одном формате —
`openspec/` (спеки) и `system-context/` (карта, трассировка, вопросы).

```
system-analysis/
  skills/<sa-*>/SKILL.md   # скиллы набора (ставятся инсталлятором)
```

## Скиллы

| Скилл | Что делает | Когда |
|---|---|---|
| [sa-scan](skills/sa-scan/) · [гайд](skills/sa-scan/guide.html) | Мастер-спека «как есть» по коду и человеческой спеке: опись входов и внешних вызовов скриптом, возможности по поведению, `openspec/specs/` (SHALL/MUST, WHEN/THEN), `system-context/` — интеграции, контракты входов и событий с вызывающими (клиенты, шлюзы, ИИ), данные (копии полей, миграции, засев, конкурентность, валидация), сущности и статусы, роли, глоссарий, «требование → код», чек-лист открытых вопросов с допущениями, карточки изменения по возможностям (~3 тыс. токенов — для слабых моделей); режим «внести ответы» с предложениями изменений в `openspec/changes/` | есть работающий сервис, нужно вести его по спекам |

Нужен только Python 3.9+. CLI OpenSpec необязателен: если он установлен, проверка запускает и `openspec validate --strict`.

Установить только этот набор:

```bash
./install.sh install -t system-analysis
```

# project-context

Скиллы, которые готовят контекст **существующего** проекта к разработке агентами: собирают то, что агенту нужно знать
о проекте, в компактные файлы и вписывают указатель на них в файл инструкций проекта (AGENTS.md, CLAUDE.md…).
Каждый скилл отвечает за свой аспект и кладёт результат в свою папку в корне репозитория проекта.

```
project-context/
  skills/<skill-name>/SKILL.md   # скиллы этой темы (ставятся инсталлятором)
```

## Скиллы

| Скилл | Что делает |
|---|---|
| [web-design-context](skills/web-design-context/) | Дизайн веб-проекта из того, что рисует браузер: основы (цвета с CSS-переменными, типографика, отступы, движение), детали с вариантами и разбором канон/шум, схемы разделов, шрифты и иконки, эталон для сверки; при доступе к коду — где заданы токены, темы, варианты и компоненты, со ссылками «деталь → файл». Результат — `design-context/`. Нужен Node.js 18+ (Playwright ставится через `./install.sh deps`) |

Дальше по плану: архитектура и код, API, предметная область — по скиллу на аспект, с тем же принципом
«компактный слой для агента + указатель в инструкциях проекта».

Установить только эту тему:

```bash
./install.sh install -t project-context
```

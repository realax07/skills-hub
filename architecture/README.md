# architecture

Набор скиллов **ar-*** для архитектуры за рамками одного проекта: какие системы есть, кто от кого зависит, какие события и данные
ходят между ними, что говорят документы и где они расходятся с кодом. Слой `architecture/` (лучше — свой репозиторий) читают
скиллы проектов: sa-scan и sa-change получают внешних потребителей и соседей ответом, а не вопросом.

```
architecture/
  skills/<ar-*>/SKILL.md   # скиллы набора (ставятся инсталлятором)
```

## Скиллы

| Скилл | Что делает | Когда |
|---|---|---|
| [ar-scan](skills/ar-scan/) · [гайд](skills/ar-scan/guide.html) | Ландшафт систем из кода нескольких репозиториев или пакетов монорепозитория (HTTP, gRPC, события по имени и теме, адреса из настроек, Aspire и docker-compose, общие базы и брокеры, внешние сервисы) и из документации (Confluence в HTML, mermaid, PlantUML и C4, Structurizr, AsyncAPI, ADR): карточка каждой системы — кто от неё зависит и от кого она, контракты с потребителями в других системах, сверка кода и документов с решениями, вопросы; копия карточек в проекты | систем больше одной, нужна карта связей или сверка архитектурной документации с кодом |

Нужен только Python 3.9+; git — чтобы видеть, что слой устарел.

Установить только этот набор:

```bash
./install.sh install -t architecture
```

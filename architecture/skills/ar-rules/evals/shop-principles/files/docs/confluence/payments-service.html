Payments Service

ВладелецКоманда Billing (канал #billing)
Репозиторийgit/payments
SLA99.9%, p95 < 800 мс

API

POST /api/payments — списать сумму заказа. Повторный запрос с тем же orderId возвращает уже созданный платёж (идемпотентность).

GET /api/payments/{id} — статус платежа.

События

payments.completed — результат списания; payments.refunded — возврат.

Внешние

Stripe — эквайринг.

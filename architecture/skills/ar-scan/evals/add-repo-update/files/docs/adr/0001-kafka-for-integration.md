# ADR-0001. Интеграция сервисов через Kafka

Статус: принято

## Контекст

Сервисы вызывали друг друга синхронно и читали чужие таблицы — любое изменение схемы ломало соседей.

## Решение

- Между сервисами — только публичный API и события Kafka.
- Сервис не читает и не пишет базу данных другого сервиса.
- Событие несёт всё, что нужно подписчикам, или идентификатор для запроса по API.

## Последствия

Каждый сервис владеет своей базой; общие данные — через события.

# web-design

Набор скиллов **wd-*** для дизайна веб-проектов с агентами: собрать дизайн существующего сайта, дорабатывать
в нём и создавать новый. Все скиллы говорят на одном формате — папке `design-context/` (токены, канон деталей,
схемы разделов, ассеты), поэтому результат одного сразу берёт другой.

```
web-design/
  skills/<wd-*>/SKILL.md   # скиллы набора (ставятся инсталлятором)
```

## Скиллы

| Скилл | Что делает | Когда |
|---|---|---|
| [wd-scan](skills/wd-scan/) | Собирает дизайн-контекст существующего сайта из того, что рисует браузер (и из исходников, если есть): основы с CSS-переменными, детали с разбором канон / вариант / шум, схемы разделов, шрифты, иконки, эталон для сверки, указатель в AGENTS.md. Результат — `design-context/` | есть сайт, нужно, чтобы агенты делали «как здесь» |
| [wd-fit](skills/wd-fit/) | Доработка в существующем дизайне по `design-context/`: выжимка под задачу, вёрстка через переменные и компоненты проекта, проверка соответствия в браузере и по изменённому коду | новая страница, блок, фича в уже собранном дизайне |
| wd-forge | ⏳ Новый дизайн с нуля: лучшие практики топовых решений, три диаметрально разных варианта на утверждение; результат — в формате `design-context/` для wd-fit | нового дизайна ещё нет |

Нужен Node.js 18+ и Playwright с браузером: подойдут уже установленные, иначе их поставит `scripts/setup.mjs` скилла
(общие для набора, ~150 МБ, вне папок скиллов). Общий код скиллов лежит копиями — см. `tools/shared.conf`.

Установить только этот набор:

```bash
./install.sh install -t web-design
```

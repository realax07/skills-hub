# web-design

Набор скиллов **wd-*** для дизайна веб-проектов с агентами: собрать дизайн существующего сайта, дорабатывать
в нём и создавать новый. Все скиллы говорят на одном формате — папке `design-context/` (токены, канон деталей,
схемы разделов, ассеты), поэтому результат одного сразу берёт другой.

```
web-design/
  skills/<wd-*>/SKILL.md   # скиллы набора (ставятся инсталлятором)
```

## Скиллы

| Скилл | Что делает | Когда |
|---|---|---|
| [wd-scan](skills/wd-scan/) · [гайд](skills/wd-scan/guide.html) | Собирает дизайн-контекст существующего сайта из того, что рисует браузер (и из исходников, если есть): основы с CSS-переменными и темами (тёмная), детали с разбором канон / вариант / шум, схемы разделов, шрифты, иконки, эталон для сверки, указатель в AGENTS.md. Результат — `design-context/` | есть сайт, нужно, чтобы агенты делали «как здесь» |
| [wd-fit](skills/wd-fit/) · [гайд](skills/wd-fit/guide.html) | Доработка в существующем дизайне по `design-context/`: выжимка под задачу, по запросу — три разных мокапа доработки прямо в странице сайта на выбор, вёрстка через переменные и компоненты проекта, проверка соответствия в браузере (во всех темах) и по изменённому коду | новая страница, блок, фича в уже собранном дизайне |
| [wd-forge](skills/wd-forge/) · [гайд](skills/wd-forge/guide.html) | Новый дизайн с нуля: бриф → три диаметрально разных направления (раздаёт скрипт из каталогов по лучшим практикам топовых дизайн-скиллов, с учётом языка и отрасли) → HTML-мокапы ключевых экранов и UI-кит (все детали и состояния, светлая и тёмная тема) → проверка качества и детектор шаблонного «ИИ-дизайна» → страница сравнения → утверждённое превращается в `design-context/` через wd-scan | нового дизайна ещё нет |

Нужен Node.js 18+ и Playwright с браузером: подойдут уже установленные, иначе их поставит `scripts/setup.mjs` скилла
(общие для набора, ~150 МБ, вне папок скиллов). Общий код скиллов лежит копиями — см. `tools/shared.conf`.

Установить только этот набор:

```bash
./install.sh install -t web-design
```

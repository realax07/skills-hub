# Пример 1: блок тарифов на главной

## Запрос

> Добавь на главную блок с тарифами: Старт, Про, Бизнес — у каждого описание и кнопка. В том же стиле, что сайт.

Репозиторий: статический сайт в `site/`, дизайн-контекст в `design-context/` (позиция `normalize`, канон размечен).

## Ход работы

1. `node <skill>/scripts/setup.mjs --check` — все ✓.
2. Контекст: `design-context/GUIDE.md` (на него ведёт блок в AGENTS.md).
3. `node <skill>/scripts/brief.mjs --context design-context --path / --groups buttons,cards,badges` — из выжимки:
   - позиция «приводить к канону»; цвета `#3b5bdb` var(--color-primary), `#1f2328` var(--color-text); шрифт Georgia;
   - канон: «Кнопка основная» `<button class="btn btn-primary">`, «Кнопка контурная» `btn btn-ghost`, «Карточка» `<article class="card">`, бейдж `.badge`;
   - схема раздела — `compositions/home.md`: секции hero → `#cards` (сетка `.cards`) → футер.
4. Сопоставление: тариф → «Карточка»; «Выбрать» → «Кнопка основная»; «Связаться» у «Бизнес» → «Кнопка контурная»
   (второстепенное действие); метка «новое» на «Старт» → бейдж. Сетка — тот же `.cards`, что у соседнего блока.
5. Первая версия: `<section id="pricing" class="cards">` с тремя `.card`; заголовки `h3` с `style="font-size:22px"`,
   цена — `<p style="color:#3b5bdb">`.
6. `node <skill>/scripts/check.mjs --context design-context --serve site --path / --selector "#pricing" --changed`:
   ```
   ✗ литерал #3b5bdb в site/index.html:12
       → замени на var(--color-primary)
   ! сочетание шрифта Georgia 22px / 700 не встречается на сайте — 3 эл. (например `h3` «Старт»)
       → размеры этого шрифта на сайте: 12px, 14px, 16px, 18.72px, 20px, 24px, 36px, 44px; ближайшие — 20px, 24px
   Итог: нарушений 1, предупреждений 1 — НЕ ПРОЙДЕНО
   ```
7. Исправлено: инлайн-размер у `h3` убран (как у соседних карточек, 18.72px), цена — класс со `color: var(--color-primary)` в `site.css`.
   Повторный запуск: `нарушений 0, предупреждений 0 — пройдено`.

## Результат (сообщение пользователю)

```
Блок тарифов добавлен на главную после блока карточек: site/index.html (секция #pricing), стиль цены — site/assets/site.css (.price).
Собран из канона дизайн-контекста: карточка (.card), кнопка основная «Выбрать», контурная «Связаться», бейдж «новое»; сетка — как у соседнего блока.
Проверка check.mjs: 0 нарушений, 0 предупреждений (первый круг поймал литерал цвета и размер заголовка 22px — исправлено).
Контекст снят до этой правки: после слияния стоит добавить главную в пересъёмку (wd-scan, --only home).
```

## Почему так

- Выжимка и одна схема раздела — вместо чтения всего контекста: агент сразу знает канон и место вставки.
- Сопоставление «элемент → канон» до кода не дало придумать «свою» кнопку для «Бизнес».
- Проверка поймала то, что глазами не видно: литерал вместо переменной и размер не из шкалы.

# Пример 1: лендинг обжарочной — три направления и утверждение

## Запрос

> Открываем обжарочную «Зерно», сайта нет. Покажи пару вариантов дизайна — главная и страница подписки.

## Ход работы

1. `setup.mjs` — всё ✓.
2. Бриф в `design-forge/PRODUCT.md`: продукт — свежая обжарка под заказ; аудитория — пьют кофе дома и в офисе;
   главная задача — выбрать зерно и оформить подписку; режим `persuade`; экраны: главная и подписка. Бренд-цвета нет.
   Вопрос пользователю одним сообщением: «Есть ли реальные цифры и отзывы, которые можно показать?» → «нет» — значит, без них.
3. `deal.mjs --out design-forge --mode persuade --product "Обжарочная Зерно"`:
   ```
   язык шрифтов: с кириллицей · темы: одна · отрасль: Еда, рестораны, доставка, кофе (правила — в PLAN.md)
   A: Редакционный манифест · Бордо и золото (dark) · Dela Gothic One / Onest · soft, airy, subtle
   B: Конфигуратор · Мята (light) · Playfair Display / Commissioner · sharp, regular, expressive
   C: Бенто-витрина · Слива и чернила (light) · Comfortaa / Nunito · round, compact, orchestrated
   Расстояния: ab 12.94, ac 11.97, bc 11.84
   ```
   Кириллица в названии → только шрифты с кириллицей (Fraunces или DM Serif дали бы русские заголовки в Georgia).
   Отрасль «еда» → в PLAN.md правила: фото — главный материал, меню и часы без лишних кликов, одна кнопка заказа на экран.
4. Планы. В B раздел «что тут дефолтное»: черновик начинался с героя «Лучший кофе в городе» и трёх карточек
   преимуществ — заменено на подборщик кофе сразу под заголовком, карточки — на линии-разделители.
5. Мокапы: A — огромный заголовок-позиция «Мы не обжариваем впрок» на тёмном бордо, колонки, нумерованные принципы;
   B — конфигуратор подписки (сорт, помол, частота) с живым итогом справа; C — бенто-сетка сортов недели и страница сорта.
   UI-кит каждого — из заготовки `kit.html`, адаптирован: в A кнопки плоские с заглавными, поля с подчёркиванием;
   в B острые углы и контурные вторичные; в C округлые кнопки-пилюли и мягкие метки.
6. `lint.mjs --dir design-forge`:
   ```
   A: ✗ index.html [mobile]: цели нажатия меньше 44px — a.logo «Зерно» 70×39
   C: ✗ index.html [mobile]: цели нажатия меньше 44px — a.logo «Зерно» 67×35
   C: ✗ kit.html: в UI-ките нет обязательных деталей — Поле с ошибкой (удалено при адаптации)
   Различие: ✓ ab ✓ ac ✓ bc
   ```
   Логотипы — `display:inline-flex; min-height:44px`; поле с ошибкой возвращено в кит. Повтор — 0 ошибок.
7. `compare.mjs` → `design-forge/index.html`. Пользователь: «A, но кнопку подписки сделать заметнее» —
   в A кнопка «Подписаться» переведена на `--color-accent`, PLAN.md обновлён, lint и compare снова.
   `approve.mjs --pick a --run` → `design-context/`: шрифты Dela Gothic One и Onest скачаны, детали кита — канон
   с именами («Кнопка основная», «Поле с ошибкой», «Метка»…), остальное — канон без имени.

## Результат (сообщение пользователю)

```
Три направления — design-forge/index.html (скриншоты десктопа и мобильного, плюсы и минусы):
A «Манифест» — крупная позиция «Мы не обжариваем впрок» на тёмном бордо, плакатный Dela Gothic. Самый запоминающийся.
B «Конфигуратор» — подписка собирается прямо на главной, мятный, Playfair. Для тех, кто знает, чего хочет.
C «Бенто-витрина» — сорта недели плитками, сливовый, округлый Comfortaa. Самый дружелюбный.
У каждого — UI-кит (кнопки, поля, метки, сообщения, состояния): он и станет основой дальнейших страниц.
Проверка: 0 ошибок, направления различаются. Цифр и отзывов нет — в брифе их не было.
Утверждено A (с заметной кнопкой подписки): дизайн-контекст — design-context/GUIDE.md, дальше страницы делает wd-fit.
```

## Почему так

- Направления раздал скрипт — три разных сценария (манифест / конфигуратор / витрина), а не одна страница в трёх цветах.
- Язык и отрасль учтены до вёрстки: шрифты с кириллицей, правила для еды в плане.
- Кит сделал дизайн-контекст полным: у wd-fit есть канон полей, ошибок и меток, хотя на двух экранах их почти нет.
- Раздел «что тут дефолтное» убрал шаблонный герой и карточки до вёрстки.
- Проверка поймала то, что не видно на десктопе: мелкий логотип на телефоне.
- «A, но с заметной кнопкой» — правка выбранного направления, а не четвёртое направление.

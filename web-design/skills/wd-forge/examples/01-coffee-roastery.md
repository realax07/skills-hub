# Пример 1: лендинг обжарочной — три направления и утверждение

## Запрос

> Открываем обжарочную «Зерно», сайта нет. Покажи пару вариантов дизайна — главная и страница подписки.

## Ход работы

1. `setup.mjs` — всё ✓.
2. Бриф в `design-forge/PRODUCT.md`: продукт — свежая обжарка под заказ; аудитория — пьют кофе дома и в офисе;
   главная задача — выбрать зерно и оформить подписку; режим `persuade`; экраны: главная и подписка. Бренд-цвета нет.
   Вопрос пользователю одним сообщением: «Есть ли реальные цифры и отзывы, которые можно показать?» → «нет» — значит, без них.
3. `deal.mjs --out design-forge --mode persuade --product "Обжарочная Зерно"`:
   ```
   A: Сначала демо · Северный сланец (light) · DM Serif Display / DM Sans · sharp, regular, orchestrated
   B: Бенто-витрина · Бордо и золото (dark) · Instrument Serif / Geist · soft, compact, orchestrated
   C: Редакционный манифест · Небо и солнце (light) · Fraunces / Work Sans · round, airy, expressive
   Расстояния: ab 12.45, ac 12.02, bc 11.78
   ```
4. Планы. В A раздел «что тут дефолтное»: черновик начинался с героя «Лучший кофе в городе» и трёх карточек
   преимуществ — заменено на подборщик кофе сразу под заголовком, карточки — на линии-разделители.
5. Мокапы: A — подборщик из трёх вопросов над сгибом и тарифы подписки; B — бенто-сетка сортов недели на тёмном фоне
   и страница сорта; C — огромный заголовок-позиция «Мы не обжариваем впрок», колонки, нумерованные принципы и лонгрид.
6. `lint.mjs --dir design-forge`:
   ```
   A: ✗ index.html [mobile]: цели нажатия меньше 44px — a.logo «Зерно» 70×39
   B: ✗ index.html [mobile]: цели нажатия меньше 44px — a.logo «Зерно» 67×35
   Различие: ✓ ab ✓ ac ✓ bc
   ```
   Логотипы — `display:inline-flex; min-height:44px`. Повтор — 0 ошибок.
7. `compare.mjs` → `design-forge/index.html`. Пользователь: «C, но кнопку подписки сделать заметнее» —
   в C кнопка «Заказать» переведена на `--color-accent`, PLAN.md обновлён, lint и compare снова.
   `approve.mjs --pick c --run` → `design-context/`: шрифты Fraunces и Work Sans скачаны, детали — канон.

## Результат (сообщение пользователю)

```
Три направления — design-forge/index.html (скриншоты десктопа и мобильного, плюсы и минусы):
A «Сначала демо» — подбор кофе в три вопроса прямо на главной, строгий сланцевый, DM Serif. Для новичков.
B «Бенто-витрина» — сорта недели плитками на тёмном бордо с золотом. Ощущение премиума.
C «Манифест» — крупная позиция «Мы не обжариваем впрок», журнальная вёрстка, Fraunces. Самый запоминающийся.
Проверка: 0 ошибок, направления различаются. Цифр и отзывов нет — в брифе их не было.
Утверждено C (с заметной кнопкой подписки): дизайн-контекст — design-context/GUIDE.md, дальше страницы делает wd-fit.
```

## Почему так

- Направления раздал скрипт — три разных сценария (подбор / витрина / манифест), а не одна страница в трёх цветах.
- Раздел «что тут дефолтное» убрал шаблонный герой и карточки до вёрстки.
- Проверка поймала то, что не видно на десктопе: мелкий логотип на телефоне.
- «C, но с заметной кнопкой» — правка выбранного направления, а не четвёртое направление.

# Источники и лицензии

wd-forge опирается на идеи топовых открытых дизайн-скиллов (исследование 2026-11-18). Тексты, каталоги и код
скилла написаны заново своими словами; чужой текст и данные не копировались. Если при доработке что-то будет взято
дословно (текст правил, строки каталогов, код), сохрани уведомление о лицензии источника рядом с заимствованием.

| Источник | Лицензия | Идеи, которые взяты (пересказ) |
|---|---|---|
| [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) — Anthropic | Apache-2.0 | план до кода (предмет, аудитория, задача → компактные токены → каркас → самопроверка «что тут дефолтное»); узнаваемые кластеры ИИ-дизайна; одно оркестрованное движение; пол качества (адаптив, фокус, reduced-motion, контраст) |
| [Impeccable](https://github.com/pbakaus/impeccable) — Paul Bakaus | Apache-2.0 | режимы поверхности и смелость по режиму; бриф продукта как вход; детерминированный детектор «тел» шаблонного дизайна на отрисованной странице. Телеметрия и хуки не используются |
| [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — Next Level Builder | MIT | выбор стиля по данным (каталоги стилей, палитр, шрифтовых пар, отраслевых правил) и скриптом, а не по вдохновению; чек-лист перед сдачей |
| [taste-skill](https://github.com/Leonxlnx/taste-skill) — Leonxlnx | MIT | раздача направления скриптом из каталогов (раскладка, палитра, шрифты, радиус); проверка в настоящем Chrome с кругами исправлений; запрет на выдуманные отзывы и цифры |
| [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines) — Vercel | MIT | проверяемые правила интерфейса: фокус, цели нажатия 24/44, reduced-motion, анимация только transform/opacity, размеры картинок, все состояния |

Шрифты каталога — из Google Fonts под SIL Open Font License: их можно подключать и встраивать в мокапы и продукт.

Отличие wd-forge от источников: ни один не даёт **трёх максимально удалённых направлений на утверждение** и выхода
в формате, который подхватывает следующий скилл (wd-scan → `design-context/` → wd-fit).

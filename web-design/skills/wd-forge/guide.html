Веб-дизайн · wd-forge

wd-forge: новый дизайн с нуля — три по-настоящему разных направления

Скилл придумывает дизайн продукта, которого ещё нет: скрипт раздаёт три максимально далёких направления, модель верстает мокапы ключевых экранов и UI-кит, браузер проверяет качество и шаблонность, человек выбирает — и выбранное становится дизайн-контекстом для разработки.

Что даёт

Новый дизайн обычно проваливается двумя способами: усреднённый «ИИ-дизайн» (Inter, фиолетовый градиент, одинаковые карточки) или три варианта, отличающиеся оттенком кнопки. wd-forge закрывает оба.

Три направления от скрипта

deal.mjs выбирает из каталогов (33 архетипа, 28 палитр, 31 шрифтовая пара) три набора с максимальным расстоянием по всем осям — разные даже на слабых моделях.

Мокапы экранов

Статичный HTML ключевых экранов на токенах направления, с мобильной версией и реалистичным текстом без выдуманных отзывов и цифр.

UI-кит на всё

kit.html в каждом направлении: кнопки, поля с ошибкой, флажки, метки, таблица, вкладки, сообщения, пустое состояние, загрузка, диалог — в светлой и тёмной теме.

Проверка качества

lint.mjs на 1440, 768 и 390 px: контраст, цели нажатия, шрифты и цвета вне токенов, детали не из кита, шаблонные приёмы и мера различия направлений.

Страница сравнения

index.html: три направления рядом — скриншоты, токены, идея, плюсы и минусы, итог проверки.

Контекст для разработки

approve.mjs превращает выбранное в design-context/ по формату wd-scan: детали кита — канон с именами. Дальше страницы делает wd-fit.

Когда звать

Когда дизайна ещё нет или его делают заново.

Подходит

  • «Сделай дизайн сайта, лендинга, кабинета», «предложи концепции», «макеты на выбор».
  • Редизайн с нуля, визуальный стиль для нового продукта.
  • Даже «сделай красиво» или «покажи пару вариантов».

Не подходит

  • Доработка в уже существующем дизайне — wd-fit.
  • Собрать дизайн с готового сайта — wd-scan.

Примеры из прогонов

Из разобранного прогона «лендинг обжарочной» (examples/01-coffee-roastery.md).

Кириллица в названии → только шрифты с кириллицей; отрасль «еда» → правила в PLAN.md.

deal.mjs --out design-forge --mode persuade --product "Обжарочная Зерно"
язык шрифтов: с кириллицей · темы: одна · отрасль: Еда, рестораны, доставка, кофе
A: Редакционный манифест · Бордо и золото (dark) · Dela Gothic One / Onest · soft, airy, subtle
B: Конфигуратор · Мята (light) · Playfair Display / Commissioner · sharp, regular, expressive
C: Бенто-витрина · Слива и чернила (light) · Comfortaa / Nunito · round, compact, orchestrated
Расстояния: ab 12.94, ac 11.97, bc 11.84

Поймано то, что не видно на десктопе.

lint.mjs --dir design-forge
A: ✗ index.html [mobile]: цели нажатия меньше 44px — a.logo «Зерно» 70×39
C: ✗ index.html [mobile]: цели нажатия меньше 44px — a.logo «Зерно» 67×35
C: ✗ kit.html: в UI-ките нет обязательных деталей — Поле с ошибкой (удалено при адаптации)
Различие: ✓ ab ✓ ac ✓ bc

Что получает пользователь.

A «Манифест» — крупная позиция «Мы не обжариваем впрок» на тёмном бордо, плакатный Dela Gothic. Самый запоминающийся.
B «Конфигуратор» — подписка собирается прямо на главной, мятный, Playfair. Для тех, кто знает, чего хочет.
C «Бенто-витрина» — сорта недели плитками, сливовый, округлый Comfortaa. Самый дружелюбный.
Проверка: 0 ошибок, направления различаются. Цифр и отзывов нет — в брифе их не было.
Утверждено A: дизайн-контекст — design-context/GUIDE.md, дальше страницы делает wd-fit.

Главные правила

Почему скилл ведёт себя так, а не иначе.

  • Три разных, а не три оттенка.Другой архетип — другая раскладка и сценарий. Оси не правят руками «под вкус»: разность пропадёт.
  • Смелость по режиму.Лендинг — смело, с одним запоминающимся приёмом; рабочий интерфейс — сдержанно. Игривый шрифт в CRM — ошибка.
  • Сначала план, потом код.Раздел «что тут дефолтное» — обязательная самопроверка против шаблона.
  • Только токены.Литерал цвета ломает вторую тему.
  • Без выдумок и утверждает человек.Отзывы, клиенты, цифры — только из брифа. Скрипт раздаёт, модель верстает, выбирает человек.

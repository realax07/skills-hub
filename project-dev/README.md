# project-dev

Скиллы, которые **разрабатывают** существующий проект агентами по контексту, собранному скиллами темы
[project-context](../project-context/): берут компактный слой контекста, делают изменение в коде проекта
и проверяют результат против этого контекста — измеримо, а не на глаз.

```
project-dev/
  skills/<skill-name>/SKILL.md   # скиллы этой темы (ставятся инсталлятором)
```

## Скиллы

| Скилл | Что делает |
|---|---|
| [design-context-dev](skills/design-context-dev/) | Доработка интерфейса в существующем дизайне по `design-context/`: выжимка токенов и канона под задачу, вёрстка через переменные и компоненты проекта, проверка в браузере — цвета и шрифты вне палитры, новые варианты вместо канона, литералы вместо переменных. Нужен Node.js 18+ (Playwright — общий с web-design-context) |

Общий код с web-design-context (извлечение в странице, загрузка Playwright) лежит копиями — см. `tools/shared.conf`.

Установить только эту тему:

```bash
./install.sh install -t project-dev
```

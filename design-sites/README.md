# design-sites

Скиллы и harness для дизайна и вёрстки сайтов.

```
design-sites/
  skills/<skill-name>/SKILL.md   # скиллы этой темы (ставятся инсталлятором)
  harness/                       # (опционально) правила, команды, хуки под агентов
```

# Просмотр заказов

## Purpose
Покупатель видит свои заказы, менеджер и администратор — все заказы.

## Requirements

### Requirement: Список заказов
Система SHALL возвращать до 100 последних заказов, новые первыми: покупателю — только его, менеджеру и администратору — все.

#### Scenario: Покупатель видит свои
- **GIVEN** у покупателя 2 заказа, у другого — 3
- **WHEN** покупатель запрашивает список
- **THEN** возвращаются только его 2 заказа

#### Scenario: Менеджер видит все
- **WHEN** менеджер запрашивает список
- **THEN** возвращаются заказы всех покупателей

### Requirement: Карточка заказа
Система SHALL возвращать заказ с позициями; чужой заказ покупателю не показывается.

#### Scenario: Чужой заказ
- **WHEN** покупатель запрашивает заказ другого покупателя
- **THEN** возвращается 404, как будто заказа нет

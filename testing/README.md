# testing

Набор скиллов **qa-*** для тестирования при переводе проекта на агентную разработку: тест-кейсы живут в репозитории как md
(md первичен), агенты находят нужные кейсы под задачу и обновляют их вместе с кодом. Скиллы говорят на одном формате — `test-cases/`.

```
testing/
  skills/<qa-*>/SKILL.md   # скиллы набора (ставятся инсталлятором)
```

## Скиллы

| Скилл | Что делает | Когда |
|---|---|---|
| [qa-scan](skills/qa-scan/) · [гайд](skills/qa-scan/guide.html) | Переносит тест-кейсы из Test IT, Zephyr Scale, TestRail, TestLink (API с токеном из окружения или файл выгрузки XML/CSV/xlsx/JSON) в `test-cases/`: файл на кейс, иерархия TMS папками, общие шаги, параметры, требования, автотесты; секреты из шагов скрываются до записи на диск; роутинг для агентов — `ROUTING.md`, индексы по возможностям sa-scan, коду, требованиям, тегам, автотестам и `route.py find`; отчёт о качестве, вопросы человеку, указатель в AGENTS.md, повторный импорт без потери правок в md | кейсы в TMS, а агенты должны их видеть; переезд из TMS в репозиторий |

Нужен только Python 3.9+. Дальше в наборе (план): покрытие кейсы ↔ спека ↔ автотесты, автотесты по кейсам, выгрузка md → TMS.

Установить только этот набор:

```bash
./install.sh install -t testing
```

# Куда ставятся скиллы и переносимость

Формат Agent Skills (папка со SKILL.md) читают разные агенты. Скилл, написанный нейтрально, работает во всех.

## Папки скиллов

| Агент | Глобально | В проекте |
|---|---|---|
| Claude Code | `~/.claude/skills/<скилл>/` | `.claude/skills/<скилл>/` |
| Codex CLI | `~/.codex/skills/<скилл>/` | `.agents/skills/<скилл>/` |
| OpenCode | `~/.config/opencode/skills/<скилл>/` | `.opencode/skills/<скилл>/` |
| Qwen Code | `~/.qwen/skills/<скилл>/` | `.qwen/skills/<скилл>/` |
| Hermes Agent | `~/.hermes/skills/<категория>/<скилл>/` | — |
| общий стандарт | `~/.agents/skills/<скилл>/` | `.agents/skills/<скилл>/` |

Пути меняются от версии к версии: если агента нет в таблице или путь не работает — проверь его документацию
(раздел про skills / SKILL.md) и скажи пользователю, что нашёл. Не угадывай молча.

Скилл подхватывается после перезапуска агента (или новой сессии).

## Как выбрать, куда класть

1. Пользователь назвал место — туда.
2. Работаешь в репо-хабе скиллов (есть `agents.conf`, папки `<тема>/skills/`, AGENTS.md с правилами) —
   в тему хаба, по его правилам; ставит потом инсталлятор хаба.
3. Скилл про конкретный проект — в проектную папку агента, чтобы он ехал вместе с репо.
4. Иначе — в глобальную папку текущего агента.

Сообщи пользователю итоговый путь и как установить в другие агенты (скопировать папку или симлинк).

## Правила переносимости

- **Имена инструментов не упоминай.** «Прочитай файл», «найди в коде», «запусти команду» — каждый агент сопоставит со своими инструментами.
- **Пути — относительно папки скилла.** Скрипты запускаются как `python3 scripts/x.py`; агенты, которые запускают из другой папки, сами подставят путь скилла.
- **Только стандартные ключи frontmatter**: `name`, `description`, `license`, `allowed-tools`, `metadata`, `compatibility`.
  Агент-специфичные расширения ломают загрузку в других агентах.
- **Плоская папка**: агенты кладут скиллы в одну папку, поэтому имя уникально среди всех скиллов пользователя.
- **Без симлинков внутри скилла** и без зависимости от расположения рядом с другими скиллами.
- **Зависимости вне папки скилла** (см. [scripts.md](scripts.md#зависимости)) — скилл может быть read-only.
